# Новости секунды для Android

Нативный Android-клиент открывает защищённую версию сайта на одном домене с API.
Это исключает проблемы CORS и DuckDuckGo, сохраняя Raspberry Pi источником данных.

## Сборка APK

1. Откройте папку `android` в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите **Build → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Минимальная версия Android: 8.0 (API 26).
