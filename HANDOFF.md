# Передача проекта «НОВОСТИ СЕКУНДЫ»

Документ для того, кто продолжит работу — человека или другой модели.
Состояние на 9 августа 2026 года, коммит `08adfdc`.

---

## 1. Что это за проект

Новостной сайт с пользовательскими публикациями и модерацией.

| Часть | Технологии | Где живёт |
|---|---|---|
| Фронтенд | React 18, Vite 5, React Router 6, Tailwind, axios | GitHub Pages |
| Бэкенд | Node 22, Express 4, JWT, multer | Raspberry Pi 4 дома у владельца |
| База и файлы | Supabase (Postgres + Storage) | Облако, бесплатный тариф |

Адрес сайта: **https://news-seconds.duckdns.org**
Репозиторий: **WingedSaga/news-seconds**, ветка `main`.

### Правила оформления, которых держится проект

- Весь текст интерфейса **на русском**.
- Иконки только из `lucide-react`. **Эмодзи не используются нигде.**
- Палитра зелёная: `#2E7D32` (`brand`), `#43A047` (`brand-hover`),
  `#A5D6A7` (`brand-accent`), `#1B5E20` (`brand-dark`), текст `ink`.
- Шрифты свои, лежат в `client/src/fonts`: Inter для интерфейса,
  Source Serif 4 для заголовков.
- Комментарии в коде — по-русски, объясняют **почему**, а не что.

## 2. Как всё связано

```
Браузер
  ↓ https://news-seconds.duckdns.org          (GitHub Pages, статика)
  ↓ VITE_API_URL — переменная сборки
  ↓ https://wingedsaga.tail7db1c9.ts.net/api  (Tailscale Funnel)
  ↓ 127.0.0.1:4000                            (Express на Raspberry Pi)
  ↓
Supabase: Postgres + Storage
```

Ключевые тонкости, на которых легко споткнуться:

1. **`VITE_BASE_PATH=/`** в `.github/workflows/deploy-client.yml`. Для своего
   домена — корень. Если поставить `/news-seconds/`, страница будет пустой.
2. **`client/public/CNAME`** содержит `news-seconds.duckdns.org`. Файл обязан
   попадать в артефакт, иначе GitHub сбрасывает привязку домена при каждом
   деплое.
3. **`VITE_API_URL`** задаётся не в коде, а в GitHub → Settings → Secrets and
   variables → Actions → **Variables**. В workflow есть запасное значение с
   мёртвым Render — на него полагаться нельзя.
4. **Запись `news-seconds.duckdns.org` нельзя переводить на домашний IP** —
   она держит привязку GitHub Pages. У Pi отдельный адрес `ts.net`.

## 3. Сервер на Raspberry Pi

- Пользователь: `wingedsaga`, каталог `/home/wingedsaga/news-seconds`
- Служба systemd: `news-seconds` (`/etc/systemd/system/news-seconds.service`)
- Порт 4000, наружу — через `tailscale funnel --bg 4000`
- Переменные окружения: `server/.env`, права `600`, в git не попадает

Обычные команды:

```bash
systemctl status news-seconds --no-pager
journalctl -u news-seconds -n 50 --no-pager
sudo systemctl restart news-seconds

# обновить код после изменений в репозитории
cd ~/news-seconds && git pull && cd server && npm ci --omit=dev
sudo systemctl restart news-seconds
```

Правильный лог запуска — три строки без ошибок:

```
[server] НОВОСТИ СЕКУНДЫ API запущен на порту 4000
[server] подтверждение почты: выключено — аккаунты активны сразу после регистрации
[schema] структура базы соответствует коду
```

### Заметные решения и почему они такие

**Ответы на комментарии** (`server/db/migrations/008`, `client/src/pages/Article.jsx`).
Вложенность ровно одна: ответ на ответ сервер прикрепляет к началу ветки.
Три уровня отступов на телефоне превращают текст в столбик по два слова.
Клиент **сам** доходит до корня ветки (`rootOf` в `threads`), не доверяя
`parent_id` — иначе ответ на ответ пропадал бы с экрана. Удаление уносит всё
поддерево, как каскад в базе.

**Сжатие видео** (`server/services/mediaCompressor.js`).
Supabase на бесплатном тарифе не берёт файл больше 50 МБ. Принимаем 100 МБ и
пережимаем лишнее: три ступени 720p → 480p → 360p, останавливаемся на первой
подошедшей. Файл кладётся на диск, а не в память — сотня мегабайт в RAM на Pi
ни к чему. Временные файлы убираются в `finally`. Без ffmpeg сервер один раз
пишет в лог команду установки и просто отклоняет тяжёлые файлы.

**Устойчивость к неприменённым миграциям** (`server/db/schemaState.js`).
PostgREST роняет весь запрос, если попросить несуществующую колонку. Поэтому
на старте проверяем, какие колонки есть, и собираем `select` по факту. Так
отставшая база тормозит одну возможность, а не весь сайт.

**Счётчик просмотров** (`server/utils/viewGuard.js`). Дедупликация в памяти по
идентификатору пользователя либо IP и User-Agent, окно 6 часов, потолок 50 000
записей. Обновление страницы больше не накручивает счётчик.

**Кавычки в конфиге Tailwind.** `'"Source Serif 4"'` — без кавычек цифра в
имени делает запись невалидной и браузер молча выбрасывает шрифт. Ловилось
тяжело, не убирайте кавычки.

## 5. Что осталось сделать

### Обязательное, за владельцем

1. **Перевыпустить три ключа.** Они полностью засветились на скриншотах в
   переписке: `SUPABASE_SERVICE_ROLE_KEY` (полный доступ к базе в обход правил,
   самый важный), `RESEND_API_KEY`, `JWT_SECRET`. Порядок: Supabase → Project
   Settings → API → Rotate; resend.com/api-keys → удалить старый;
   `openssl rand -base64 32` для нового JWT. После каждой замены — новое
   значение в `server/.env` и `sudo systemctl restart news-seconds`. Смена
   `JWT_SECRET` разлогинит всех, это нормально. Заодно стоит отозвать пароль
   приложения Gmail на myaccount.google.com/apppasswords.
2. **Две миграции в Supabase → SQL Editor**, если ещё не прогнаны:

```sql
alter table public.articles drop constraint if exists articles_category_check;
alter table public.articles
  add constraint articles_category_check
  check (category in ('news', 'joke', 'weather', 'other'));

alter table public.comments
  add column if not exists parent_id uuid references public.comments (id) on delete cascade;
create index if not exists comments_parent_idx on public.comments (parent_id, created_at);
```

3. **`sudo apt install -y ffmpeg`** на Pi — без него сжатие видео не работает.
4. **Enforce HTTPS** в Settings → Pages, когда выпустится сертификат.

### Открытые вопросы

- **Почта выключена.** `BREVO_API_KEY` и `RESEND_API_KEY` в `.env` пустые,
  поэтому подтверждение почты отключено и аккаунты активны сразу. Вернуть
  лучше через **Brevo**: ему не нужен свой домен, достаточно подтвердить один
  адрес-отправитель, 300 писем в сутки бесплатно. Resend без своего домена шлёт
  только на адрес владельца аккаунта, а домен на DuckDNS подтвердить нельзя —
  там нет ни MX, ни DKIM-записей.
- **Мёртвые разделы.** Маршруты `/jokes` и `/weather` (`client/src/pages/Jokes.jsx`,
  `Weather.jsx`) ни с чем не связаны — лента давно единая. Владельцу
  предлагалось их удалить, ответа не было.
- **Ветка `gh-pages`** осталась от временного обходного пути, когда GitHub
  Actions лежали. Не используется, можно удалить.
- **Проверка кадра видео в ленте.** Механизм рабочий, но в песочнице его не
  посмотреть: сборка Chromium без проприетарных кодеков не декодирует H.264.
  С файлом WebM всё показывается (`readyState` 4), с MP4 — нет. На настоящих
  браузерах должно работать; если владелец сообщит о чёрном прямоугольнике,
  нужен запасной вариант — плашка со значком видео, как сделано для аудио.

## 6. Как проверять работу

В песочнице нет доступа к боевому сайту: прокси режет `duckdns.org`,
`github.io`, `*.onrender.com`, `*.ts.net`. Поэтому проверка делается локально.

```bash
# сборка
cd client && npx eslint src && npm run build

# локальный сервер со сборкой, отдаёт index.html на любой маршрут
python3 <путь-к-scratchpad>/spa.py     # слушает 127.0.0.1:8910
```

Дальше Playwright с готовым Chromium: `executablePath: '/opt/pw-browsers/chromium'`.
Запросы к бэкенду подменяются через `page.route('**/api/**', ...)`.
Для входа под пользователем: `localStorage.setItem('ns_token', 'что угодно')`
плюс мок `/auth/me`, возвращающий `{ user: {...} }`.

Проверка горизонтальной прокрутки, самая надёжная:

```js
await page.evaluate(() => window.scrollTo(9999, 0));
const overflow = await page.evaluate(() => window.scrollX);  // должно быть 0
```

Ширина экрана владельца — **393 px** (Poco X6 Pro), проверяйте на ней.

Статус деплоя — через GitHub MCP, `actions_list` по `deploy-client.yml`.
Сборка идёт около 40 секунд. Ответ этого инструмента огромный, читать его лучше
через `python3 -c "import json; ..."` по файлу, куда он сохраняется.

## 7. Как работать с владельцем

- Пишет по-русски, коротко, часто с опечатками. Отвечать так же по-русски.
- Просит сообщать, когда задеплоится. Стоит проверять статус прогона и писать
  результат, а не обещание.
- Ценит прямоту: если что-то не проверено или сломано по вине исполнителя —
  это лучше сказать прямо, без смягчений.
- Задачи ставит одной строкой, без подробностей. Уточнять стоит только когда
  разные прочтения ведут к разной работе.
